# Сложно сосредоточиться

Адаптивная страница с двумя цветовыми темами: тёмной («неон») и светлой («день»). Проектная работа 3 спринта.

Репозиторий: https://github.com/posev0971/slozhno-sosredotochitsya-ad

Макет: https://www.figma.com/design/qhgelUhPHUbJVf3jgZsaD7/3-спринт.-Проектная-работа

## Что реализовано

- Mobile first вёрстка, брейкпоинты 768px и 1024px, без горизонтального скролла
- Две цветовые схемы и режим «Авто», который следует системной теме
- Переключение темы кнопками «День / Авто / Неон», выбор сохраняется в localStorage
- Цвета, шрифт и отступы вынесены в CSS-переменные
- Шапка и футер на гридах, декоративные уголки и метка REC на псевдоэлементах
- Адаптивный заголовок на clamp(), галерея на гриде с ленивой загрузкой
- Семантическая разметка, у картинок есть alt, видимый фокус для клавиатуры

## Структура проекта

- index.html
- fonts/ — шрифт IBM Plex Mono
- images/ — фоны и картинки галереи
- scripts/script.js — переключение тем
- styles/globals.css — сброс стилей
- styles/variables.css — переменные основной (тёмной) темы
- styles/style.css — основные стили и медиазапросы
- styles/light.css — переменные светлой темы

## Как запустить

Откройте index.html в браузере, сборка не нужна.

## Технологии

HTML5, CSS3 (grid, flex, custom properties, clamp, media queries), JavaScript.
